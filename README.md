#Reruistion system:
Overview:

#This is my Assessment 2 project. My name is Apurba paul & student ID is 20261752. I created this Python program to manage staff requisitions using a class called RequisitionSystem.

#Working process:

#The program permitss staff to submit requisitions with item names and prices. It calculates the total cost and generates a requisition ID. If the total is below $500, it is automatically approved. If the total is $500 or more, it stays pending until a manager approves or rejects it.

#Main Features:

#The program can add requisitions, approve or reject pending requisitions, display all requisition details and show statistics. The statistics include total submitted, approved, pending and not approved requisitions.

#Project File:

#The main file is called requisition_system.py. It contains the RequisitionSystem class and all the program code.

#How to Run:

#Open the project folder in Visual Studio Code, open requisition_system.py and run the Python program. The results will appear in the terminal.

#Testing:

#I tested the program using different requisition amounts, including below $500, exactly $500 and above $500. I also tested manager decisions and checked the statistics.
