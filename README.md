
#Requisition System
#Overview:

#This is my Assessment 2 project. My name is Apurba Paul and my student ID is 20261752. I created this Python program to manage #staff requisitions using a class called RequisitionSystem.

#Working Process:

#The program allows staff to enter requisition details, including date, staff ID, staff name, item names and prices. It #calculates the total cost and generates a unique requisition ID. If the total is below $500, the requisition is automatically #approved. If the total is $500 or more, it remains pending until a manager approves or rejects it.

#Main Features:

#The program can create requisitions, approve or reject pending requisitions, display all requisition details and show #statistics. The statistics include total requisitions, approved, pending and not approved requisitions.

#Project Files:

#The project contains two Python files. The main file is called requisition_system.py, which contains the RequisitionSystem #class and its methods. The second file is called test_requistion.py, which takes user input and runs the program through a menu.

#How to Run:

#Open the project folder in Visual Studio Code. Open and run test_requistion.py. Enter the required details in the terminal and #select options from the menu to use the system.
